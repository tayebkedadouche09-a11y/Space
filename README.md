# NUMI — Digital Business OS

Cinematic marketplace for finished website systems.

**Version:** 3.3.0 — Production Truth Edition

## Stack
- React + TypeScript + Vite
- Express + tRPC
- Drizzle ORM + MySQL
- Stripe / Chargily / PayPal
- Native GitHub + Vercel provisioning

## Quick start
```bash
cp .env.example .env
pnpm install
pnpm db:push
pnpm dev
```

See `docs/PRODUCTION-CHECKLIST.md` and Admin → **System Truth** before going live.
